# Brand source

`UL_logo_black_RGB.svg` is UL's official logotype, from [Region Uppsala's
graphic profile](https://regionuppsala.se/det-har-gor-vi/om-region-uppsala/region-uppsalas-varumarken/varumarke-och-grafisk-profil-for-ul/logotyper/).
It is kept here so the integration's icon can be re-rendered rather than
resampled.

`../../custom_components/ul_transport/icon.png` is this mark centred on a disc
of UL's brand yellow — Pantone 116 C, `#FFD300` — at 78% of the disc's width,
which is the clear space UL's own profile picture gives it. Rendered at 1024 px
and downsampled to 256, so the edge is antialiased rather than resampled from a
bitmap.

The UL logotype and the colour are UL's trademarks, used here to identify the
service this integration talks to. This project is not affiliated with or
endorsed by UL.
